## ランタイムの出所確認

2026-10-12に、固定された公式Python 3.13.16 x64配布版を使ってWindowsアプリを最後までビルドし、`--require-verified-runtime` の検査に合格しました。公式アーカイブ、Windowsマニフェスト、SPDX SBOMの対応を確認し、展開した原本3,159ファイルと、同梱するすべてのDLL/PYDを対応する公式ランタイムのファイルと比較しました。結果のマニフェストには `bundledRuntime.runtimeProvenanceVerified: true` と、空の `unverifiedComponents` リストが記録されています。

この検査により、以前は確認できなかったlibffiとXZのバイナリの出所を確認しました。公式SBOMにはlibffi 3.4.4とXZ/liblzma 5.2.5が記載されており、Windowsランタイムのmpdecimal 4.0.0の項目も一致しています。パッケージには、16個のライセンス・告知ファイル、`provenance/python-runtime.spdx.json` の公式SBOM、`MANIFEST.json` の出所URL・ハッシュ・バイナリの対応関係が含まれています。

この結果が確認するのは、公式配布元から取得したファイルであることと、ファイルの一致です。ソースから独立してビルドを再現したり、セキュリティ監査、法的認証、アプリの品質確認を終えたりしたわけではありません。別のPython配布版でビルドした場合は、出所未確認と記録されることがあります。ソースZIPにはランタイムを同梱していません。実際に公開するパッケージでは、[リリース手順](RELEASING.ja.md)に従って再確認してください。

## 人が行う短い確認手順

Windows ZIPを新しく展開し、ファイル名を記録してください。問題なく使えているインストール先を上書きしないでください。オーバーレイの確認には一時的なOBSシーンを使えます。配信や録画を始める必要はありません。

### 使い方に沿って導入する

1. このプロジェクトを設定したことのない人に、使いやすい言語のガイドに従ってもらいます。手順を先に説明しないでください。
2. ファイルのダウンロード、展開、アプリの起動、本人のゲーム数値の入力を進めてもらいます。最初に立ち止まった箇所、助けを求めた箇所、操作項目を見つけられなかった箇所を記録します。
3. ガイドを最後まで進め、OBSへオーバーレイを追加してもらいます。助けが必要だったか、どの手順だったかを記録します。Windowsがアプリをブロックした場合は、その表示を記録し、確認を終えるために保護機能を無効化しないでください。

### コントローラーとOBSを確認する

1. 1〜7鍵、時計回り、反時計回りの設定を完了します。各鍵盤を押し、ターンテーブルを両方向に回します。時計回り ↻ / 淡いコーラル色、反時計回り ↺ / 濃いコーラル色を確認した後、方向を交互に切り替えます。
2. 短押し、長押し、2鍵の同時押し、連打を確認します。入力中にコントローラーを外しても、表示が点灯したまま残ってはいけません。再接続し、必要ならデバイスを選び直します。
3. INFINITASにフォーカスがある状態でも、オーバーレイが入力を受け取ることを確認します。OBSでレーンの位置と落下する動きを見ます。1P/2P、ゲーム数値、必要だった補正を記録します。簡単な目視だけでタイミングが正確だとは記録しないでください。
4. 設定タブを閉じても入力が続くことを確認します。その表示を開始した単独起動のLift Traceウィンドウを閉じると、表示が止まることを確認します。
5. 任意のOBS自動起動を確認する場合は、先に単独起動のアプリを閉じます。OBSから表示を開始してOBSを閉じ、表示も止まることを確認します。単独起動のアプリがすでに動いている場合も繰り返します。この場合はOBSを閉じても既存アプリの表示が続く必要があります。

### 文書を読む

1. 確認する言語のREADMEと使い方をすべて読みます。操作項目の名前をアプリとOBSの表示と比較します。
2. 翻訳調に感じる文、説明のない用語、外部の知識が必要な手順を挙げます。可能なら該当する文を引用し、代案を書いてください。
3. コントローラーの入力と譜面ノーツの違い、自動・手動の高さ、2つのウィンドウを閉じたときの動作が明確か確認します。

## 報告用テンプレート

Issueやレビューメモにコピーして使ってください。不明な項目は空欄で構いません。スキップした検査や進められなかった検査も有用な情報です。合格したものとして記録しないでください。

```text
日付：
ZIPファイル名 / バージョン：
WindowsとOBSのバージョン（分かる場合）：
使用した言語：
コントローラーとINFINITASの接続モード（試した場合）：

実施した検査：
項目ごとの結果：合格 / 不合格 / 実施不能 / 未実施

表現の提案やその他のメモ：

確認方法：人 / 自動ツール / AIを使った確認
```

ログを共有する前に、個人のパス、ユーザー名、デバイス識別子を除いてください。受け入れた報告は、ビルドと確認範囲を添えてここに要約します。1つの環境の結果を、全体の互換性保証へ広げないでください。
