# 처음부터 따라 하는 사용 안내

[한국어](USER_GUIDE.ko.md) · [日本語](USER_GUIDE.ja.md) · [English](USER_GUIDE.en.md) · [처음으로](../README.md)

**파일 받기 → 압축 풀기 → 프로그램 켜기 → 게임 수치 입력 → 건반·스크래치 설정 → OBS에 붙여넣기** 순서로 진행합니다. 명령어를 입력하거나 Python을 설치할 필요는 없습니다.

Windows 10/11(64비트) PC와 컨트롤러를 준비하세요. OBS Studio와 INFINITAS는 별도로 필요합니다. 아래의 OBS 단계는 **OBS에 게임 화면이 이미 보이는 상태**에서 진행합니다.

## 1. 파일을 받아서 프로그램 켜기

1. 프로젝트의 GitHub 페이지에서 **Releases**를 누릅니다. 보통 오른쪽에 있습니다.
2. 최신 버전을 열고 **Assets**를 누릅니다. 받을 수 있는 파일 목록이 나타납니다.
3. 이름이 `lift-trace-windows-x64-`로 시작하고 `.zip`으로 끝나는 파일을 눌러 받습니다. 중간 숫자는 버전이므로 달라져도 괜찮습니다. “Source code” 또는 이름에 “source”가 있는 파일은 선택하지 마세요.
4. 받은 파일을 오른쪽 클릭해 **압축 풀기**를 선택합니다. 저장 위치를 고르는 창이 나오면 **문서** 같은 폴더를 선택하고 **압축 풀기**를 누릅니다.
5. 새로 생긴 폴더 안에서 **LiftTrace** 폴더를 열고 **LiftTrace.exe**를 더블클릭합니다. Windows 설정에 따라 이름이 **LiftTrace**로만 보일 수도 있습니다.

**확인할 결과:** 작은 **Lift Trace 창**과 인터넷을 볼 때 사용하는 브라우저의 **설정 화면**이 열립니다. 설정 화면이 안 열리면 작은 창의 **설정 열기**를 누르세요. 언어가 다르면 **한국어**를 선택합니다.

압축을 푼 폴더는 통째로 보관하세요. **LiftTrace.exe만 다른 곳으로 옮기지 마세요.** 다음부터도 같은 파일을 더블클릭하면 됩니다.

이 안내에서 **입력 노트**는 건반을 누르거나 스크래치를 돌린 내용을 화면에 그린 표시입니다. 게임 채보를 읽어서 표시하는 노트는 아닙니다.

## 2. 게임에 보이는 수치 입력하기

게임의 HI-SPEED 설정 화면을 열고 **본인이 사용하는 값**을 다음 칸에 입력합니다.

| 입력할 칸 | 게임에서 볼 것 |
| --- | --- |
| **녹숫** | 초록색 **NOTES TIME** 수치 |
| **리프트 (LIFT)** | 아래쪽 리프트 커버의 수치 |
| **서든 (SUDDEN+)** | 위쪽 서든 커버의 수치. 사용하지 않으면 **0** |

커버 수치가 두 곳에 보이면 위쪽 SUDDEN+와 아래쪽 LIFT를 구분하세요. HI-SPEED 배율이나 BPM은 이 칸에 넣지 않습니다.

![위 커버, 게임 노트 영역, 판정선, 아래 표시 영역을 그린 설명 그림](images/lane-layout.svg)

그림의 **A**는 위쪽 SUDDEN+, **B**는 게임 노트가 보이는 곳, **C**는 판정선, **D**는 입력 노트를 놓을 아래쪽 LIFT 영역입니다. 설명용 그림이며 수치는 예시입니다.

**높이 설정**은 **LIFT에 맞춰 자동 (추천)**으로 두세요. 예를 들어 LIFT가 **401**이면 표시 높이는 **290**으로 계산됩니다. 예시를 그대로 쓰지 말고 게임에 보이는 자신의 LIFT 값을 넣으세요. **속도 보정**은 처음에는 **1**로 둡니다.

**확인할 결과:** **오버레이 높이** 칸에 계산된 숫자가 나옵니다. 떨어지는 입력 노트는 다음 단계에서 건반 설정을 마친 뒤 확인합니다.

**높이를 자동으로 정할 때 LIFT가 0이면, 판정선 아래에 표시할 공간이 없어 입력 노트가 보이지 않습니다.** 게임에서 LIFT를 켜고 그 수치를 입력하세요. 별도의 높이를 쓰고 싶다면 **높이 설정 → 직접 정하기**를 선택하고 원하는 높이를 입력할 수도 있습니다.

## 3. 안내에 따라 건반과 스크래치 설정하기

1. 평소 INFINITAS에서 쓰는 모드로 컨트롤러를 PC에 연결합니다.
2. 설정 화면의 **입력 소스**에서 **컨트롤러 · 게임 중에도 입력 감지**를 선택합니다.
3. 바로 아래 **컨트롤러**에서 자신의 장치를 선택합니다. 목록이 비어 있으면 **검색**을 누릅니다.
4. **컨트롤러 설정**을 누릅니다. 먼저 모든 버튼에서 손을 뗍니다.
5. 안내에 따라 **1번 건반부터 7번 건반까지**, 왼쪽에서 오른쪽 순서로 하나씩 눌렀다 놓습니다. 한 번에 하나만 누르세요.
6. **시계방향 ↻** 안내가 나오면 턴테이블을 위에서 내려다봤을 때 **시계바늘이 도는 방향으로만** 돌립니다. 다른 버튼은 누르지 말고, 돌린 뒤 **시계방향 확인**을 누릅니다.
7. 다음 **반시계방향 ↺** 안내에서는 **시계바늘과 반대 방향으로만** 돌린 뒤 **반시계방향 확인**을 누릅니다.
8. 결과가 나오면 **적용**을 누릅니다. 다시 하고 싶으면 **처음부터**, 그만두려면 **취소**를 누릅니다.
9. 스크래치가 왼쪽이면 **1P**, 오른쪽이면 **2P**를 선택합니다.

**확인할 결과:** 설정을 마치고 원래 화면으로 돌아옵니다. 건반을 누르거나 스크래치를 돌리면 미리보기의 아래쪽에 입력 노트가 나옵니다. 위쪽의 게임 노트는 설명용 예시이며 실제 게임 화면이 아닙니다.

회전 방향을 다시 설정하라는 안내가 나오면 **회전 방향 다시 설정**을 누릅니다. 건반 1~7번은 그대로 두고, 시계방향부터 두 방향을 다시 확인합니다. 설정 도중 연결을 뺐다면 다시 연결하고 처음부터 진행합니다.

스크래치 표시도 확인하세요.

| 실제로 돌린 방향 | 화면에 보이는 입력 노트 |
| --- | --- |
| 시계방향 | **↻**와 **연한 산호색** |
| 반시계방향 | **↺**와 **진한 산호색** |

방향을 번갈아 돌리면 화살표와 색이 함께 바뀝니다. 반대로 보이면 **컨트롤러 설정**을 다시 진행하고, 안내한 방향으로 돌렸는지 확인하세요. 같은 방향으로 계속 돌리는 동안에는 하나로 이어져 보일 수 있습니다. 앱은 게임 채보를 읽지 않으므로 그 안의 스크래치 노트 개수까지 나누어 표시하지는 않습니다.

## 4. OBS에 주소와 크기 붙여넣기

먼저 OBS에서 **설정 → 비디오 → 기본 (캔버스) 해상도**가 **1920 × 1080**인지 확인하세요. 아래의 크기와 위치 계산은 게임이 그 화면 전체를 채우는 구성을 기준으로 합니다.

아래 단계에서는 Lift Trace 설정 화면과 OBS를 번갈아 봅니다. 입력할 칸을 클릭한 뒤 **Ctrl 키를 누른 채 A**를 누르면 그 칸의 내용이 모두 선택됩니다. 이어서 **Ctrl 키를 누른 채 V**를 누르면 선택한 내용이 복사한 내용으로 바뀝니다. 아래에서는 이를 **Ctrl+A**, **Ctrl+V**로 적습니다.

1. 처음 설정할 때는 Lift Trace의 **오버레이 표시 영역**에서 **1080p 레인 크기 맞추기**를 누릅니다. 전체 너비가 **432**로 바뀌고 각 건반과 스크래치의 폭도 함께 맞춰집니다. 앞에서 입력한 게임 수치와 컨트롤러 설정은 그대로입니다.
2. **OBS에 붙여넣을 주소 복사**를 누릅니다.
3. OBS의 **소스 목록**에서 아래쪽 **+**를 누르고 **브라우저**를 선택합니다. 이름을 **Lift Input**으로 입력하고 **확인**을 누릅니다.
4. 새로 열린 창에서 **로컬 파일**은 체크하지 않습니다. **URL** 칸을 클릭하고 **Ctrl+A**, **Ctrl+V**를 차례로 누릅니다. 기존 내용 대신 복사한 주소가 들어갑니다.
5. Lift Trace 화면으로 돌아가 **너비 복사**를 누릅니다. OBS의 **너비** 칸을 클릭하고 **Ctrl+A**, **Ctrl+V**를 누릅니다.
6. Lift Trace에서 **높이 복사**를 누릅니다. OBS의 **높이** 칸을 클릭하고 **Ctrl+A**, **Ctrl+V**를 누른 뒤 **확인**을 누릅니다.

**확인할 결과:** OBS의 소스 목록에 **Lift Input**이 생깁니다. 처음에는 검은 사각형처럼 보일 수 있습니다. 건반을 누르면 그 안에 입력 노트가 나옵니다. 다음 단계에서 이 사각형의 위치를 맞춥니다.

주소의 숫자를 외우거나 직접 입력할 필요는 없습니다. 너비와 높이도 **앱에 지금 표시된 값**을 그대로 옮기세요.

더 부드럽게 보이게 하려면 OBS에서 **Lift Input**을 더블클릭하고 **사용자 지정 프레임 레이트 사용**을 켠 뒤 **60 FPS**를 입력하세요. 해당 항목이 보일 때 설정하고 **확인**을 누르면 됩니다.

## 5. 복사한 숫자로 위치 맞추기

앱의 **가로 위치 (X)**는 왼쪽·오른쪽 위치, **세로 위치 (Y)**는 위·아래 위치입니다. **1P/2P와 LIFT 값**을 바탕으로 계산하므로 직접 계산할 필요가 없습니다.

1. OBS의 소스 목록에서 **Lift Input**을 게임 캡처보다 위로 끌어올립니다. 옆의 자물쇠가 잠겨 있다면 눌러 풉니다.
2. **Lift Input**을 오른쪽 클릭하고 **변환 → 변환 초기화**를 누릅니다. 이전에 늘이거나 자른 상태를 지우는 단계입니다.
3. 다시 오른쪽 클릭하고 **변환 → 변환 편집**을 누릅니다. **위치 정렬**은 **왼쪽 상단**, **경계 상자 유형**은 **경계 없음**으로 둡니다. 버전에 따라 경계 없음이 **자동**으로 표시될 수도 있습니다. 크기·회전·자르기 칸은 바꾸지 않습니다.
4. Lift Trace의 **가로 위치 복사**를 누릅니다. OBS의 **위치** 중 **X / 수평 위치** 칸을 클릭하고 **Ctrl+A**, **Ctrl+V**를 누릅니다.
5. Lift Trace의 **세로 위치 복사**를 누릅니다. OBS의 **위치** 중 **Y / 수직 위치** 칸에 같은 방법으로 붙여넣고 창을 닫습니다.
6. OBS 미리보기에서 사각형의 윗변이 게임 판정선에, 각 건반의 세로줄이 게임 레인에 맞는지 확인합니다. 맞으면 소스 목록에서 **Lift Input 옆 자물쇠**를 잠급니다.

**확인할 결과:** 게임의 판정선 아래에서 자신의 입력 노트가 내려옵니다. 예를 들어 1P·LIFT 401·위치 조정 0이면 X는 **75**, Y는 **433**, 높이는 **290**입니다. 예시 숫자를 외우지 말고 앱의 복사 버튼을 쓰세요.

2P 위치는 1P를 좌우 대칭으로 계산한 시작 위치입니다. 2P 실물 화면과의 일치는 아직 확인하지 않았으므로, 실제 화면을 보며 맞춰 주세요.

조금 어긋나면 앱의 **OBS 위치 조금 옮기기**를 펼칩니다. **좌우로 이동**에 **2**를 넣으면 오른쪽으로, **-2**를 넣으면 왼쪽으로 2픽셀 옮길 수 있습니다. **위아래로 이동**에 **2**를 넣으면 아래로, **-2**를 넣으면 위로 2픽셀 옮길 수 있습니다. 픽셀은 화면에서 거리를 재는 단위입니다. 값을 바꾼 뒤 해당 위치를 다시 복사해 OBS의 위치 칸에 붙여넣으세요. **1080p 레인 크기 맞추기**를 다시 누르면 두 이동 값이 모두 0으로 돌아갑니다.

폭만 다르면 **전체 레인 폭**을 바꾸고 **너비 복사**로 OBS의 브라우저 소스 **너비**를 맞춥니다. 폭을 바꿔도 계산된 시작 위치는 이동하지 않습니다.

사각형의 모서리를 끌어서 늘리거나 **화면에 맞추기**를 누르지 마세요. 원래 크기(100%)가 바뀌면 게임 레인과 맞지 않고, 세로로 늘어나면 낙하 속도도 달라 보입니다. 실수했다면 위의 **변환 초기화**부터 다시 진행합니다. 위치가 맞는데 떨어지는 속도가 다르면 **속도 보정**, 입력 노트가 너무 일찍 나오면 **표시 지연**을 조금씩 조절합니다.

## 높이나 플레이 위치를 바꿨다면

| 바꾼 것 | OBS에서 다시 붙여넣을 것 |
| --- | --- |
| 게임의 LIFT | 앱에도 새 LIFT를 넣고 **세로 위치 복사**로 변환 편집의 Y 위치를 맞춥니다. 높이를 자동으로 정하고 있다면 **높이 복사**로 브라우저 소스의 높이도 바꿉니다. |
| 높이만 직접 정하기 | **높이 설정 → 직접 정하기**에서 높이를 넣고 **높이 복사**만 합니다. Y 위치는 바뀌지 않습니다. |
| 1P ↔ 2P | 앱에서 배치를 바꾸고 **가로 위치 복사**로 변환 편집의 X 위치를 맞춥니다. |
| 좌우·위아래 이동 값 | 바꾼 쪽의 위치를 복사해 변환 편집의 X 또는 Y에 붙여넣습니다. |

**OBS에 있는 사각형의 크기와 위치까지 저절로 바뀌지는 않습니다.** 앱에서 바꾼 뒤에는 위 표처럼 OBS에도 옮겨 주세요. 표시 높이만 바꾸는 것은 낙하 속도에 영향을 주지 않습니다. 게임의 LIFT·녹숫·SUDDEN+ 수치를 바꾸는 것은 게임 속도 계산에도 영향을 줍니다.

## 다음에 사용할 때와 끝낼 때

다음에는 **LiftTrace.exe를 더블클릭 → 필요하면 컨트롤러 선택 → OBS 실행** 순서로 사용합니다. 입력 설정을 매번 처음부터 다시 할 필요는 없습니다.

설정 화면이 열린 **브라우저 탭은 닫아도 됩니다.** 입력 표시는 계속됩니다.

**작은 Lift Trace 창**은 상태 안내를 확인하세요. 그 창이 입력 표시를 새로 시작했다면 **종료**를 누르거나 창을 닫을 때 입력 표시도 멈춥니다. 사용하는 동안에는 켜 두세요.

**“이 창을 닫아도 입력 표시는 계속됩니다.”**라고 나오면 OBS나 다른 Lift Trace 창에서 이미 실행하고 있던 표시를 함께 사용 중입니다. 이 창을 닫아도 먼저 실행한 쪽은 종료되지 않습니다. 입력 표시까지 끝내려면 먼저 실행한 OBS 또는 Lift Trace 창을 닫으세요.

## 선택 사항: OBS와 같이 켜기

처음에는 위의 방법으로 동작을 확인하세요. 그다음 매번 LiftTrace.exe를 따로 열지 않고 OBS와 같이 켤 수 있습니다.

1. 작은 Lift Trace 창을 닫습니다.
2. OBS의 **도구 → 스크립트 → +**를 누릅니다.
3. 압축을 푼 LiftTrace 폴더에서 **obs-lift-trace.lua**를 선택합니다.
4. **OBS 시작 시 자동 실행**을 켜 둡니다. 다른 칸은 처음에는 바꾸지 마세요.
5. **입력 서버 시작 / 연결**을 누릅니다. 다음부터는 OBS를 켜면 입력 표시도 준비됩니다. 컨트롤러가 선택되지 않으면 **입력 설정 열기**에서 자신의 장치를 선택하세요.

OBS가 입력 표시를 새로 시작했다면 OBS를 닫을 때 함께 끝납니다. OBS를 켜기 전에 Lift Trace가 이미 실행 중이었다면 OBS를 닫아도 그 프로그램은 계속 실행됩니다. 자세한 설정은 [기술 참고](REFERENCE.md#optional-obs-startup-settings)에 있습니다.

## 선택 사항: INFINITAS 자동 표시 (미출시)

이 절은 **현재 개발 소스의 실험 기능** 안내입니다. 공개 v0.1.0 ZIP에는 없으며, 기존 수동 오버레이 설정만으로도 계속 사용할 수 있습니다. 자동 표시를 포함한 Windows 앱 빌드에는 필요한 라이브러리를 함께 넣습니다. 소스 실행은 [개발 가이드](DEVELOPMENT.md)를 따르세요.

플레이 UI가 보일 때만 카메라·오버레이·게이지 복사본 등을 함께 표시할 수 있습니다. **INFINITAS 판별 기준이 들어 있으므로 플레이 화면을 따로 등록할 필요가 없습니다.**

1. OBS의 **도구 → WebSocket 서버 설정**에서 서버를 켜고 표시된 포트와 비밀번호를 확인합니다. Lift Trace 설정 화면의 **INFINITAS 플레이 중 소스 표시 · 실험 기능**을 펼쳐 같은 값을 넣고 **OBS 연결**을 누릅니다. 연결 대상은 이 PC의 OBS입니다. 비밀번호 칸을 비우면 이전에 저장한 값을 사용합니다.
2. **OBS 장면**과 **게임 화면을 읽을 소스** 목록에서 OBS에 있는 실제 이름을 고릅니다. 화면 전체가 나오는 원본을 선택하고 OBS에서 표시를 켜 두세요. 같은 소스가 여러 번 배치되어 있으면 이름 옆의 OBS 목록 위·아래 위치 안내로 구분합니다. 게이지 복사본을 원본으로 고르지 마세요.
3. **자동으로 표시·숨길 소스**에서 카메라, 입력 오버레이, 게이지 복사본 등을 체크하고 **선택 저장**을 누릅니다. 체크하면 자동 제어 대상에 추가하고, 체크를 풀면 제외합니다. OBS 소스 자체를 삭제하는 기능은 아닙니다. 원본 캡처는 제어 대상에서 빠집니다.
4. **자동 표시 시작**을 누른 뒤 게임으로 돌아갑니다.
5. 플레이 UI가 0.2초 이어지면 선택 항목이 표시되고, 비플레이가 0.3초 이어지면 숨겨지는지 확인합니다. 선곡 → 플레이 → 결과를 직접 확인하고 원본 게임 화면은 계속 보여야 합니다. 현재 확인 근거와 남은 검사는 [검증 현황](VALIDATION.md)을 보세요.

연결된 상태에서 설정 페이지를 다시 열면 실제 이름과 저장한 선택이 복원되며, 실행 중인 자동 표시를 중지하지 않습니다. OBS에서 이름이나 항목을 바꿨다면 **목록 새로고침**으로 다시 확인하세요.

**자동 표시 중지**는 현재 표시 상태를 바꾸지 않습니다. 이후에는 OBS 눈 아이콘으로 조절할 수 있습니다. OBS 연결이 끊기거나 장면 모음을 바꾸면 다시 연결하고 항목을 확인·저장한 뒤 직접 시작해야 합니다. 실행 중 오류를 자동으로 재시도하지 않습니다. 새 설치와 일반 실행에서는 매번 직접 시작하며, OBS와 함께 시작하려면 [선택 설정](REFERENCE.md#saved-automation-startup)을 사용할 수 있습니다.

정상적으로 분류된 화면이 잠시 늦게 도착하면 그 화면을 버리고 다음 화면을 기다립니다. 짧은 지연 동안에는 이미 표시된 항목을 유지합니다. 2초를 넘긴 지연은 처리가 재개될 때 숨기며, 선곡·결과 같은 비플레이 화면을 확인한 뒤 다음 플레이에서 다시 표시합니다. 이때 자동 제어 자체를 다시 시작할 필요는 없습니다. FULL COMBO로 SCORE 글자가 바뀌는 동안에는 미리 확인한 BPM 글자 영역으로 플레이 표시를 유지합니다.

<details>
<summary>지원 범위와 추가 안내</summary>

현재는 확인한 1P 배치의 원본 1920 × 1080 캡처에서 SCORE로 플레이 진입을 확인하고 BPM 글자로 표시를 유지하며, 곡 시작 전 플레이 UI도 포함합니다. BPM 숫자나 곡명을 읽는 기능은 아닙니다. 2P·DP·다른 배치·해상도·HDR에서의 동작은 확인하지 않았고 BMS는 지원하지 않습니다. 한 장면의 최상위 항목 1–8개를 제어하며 그룹·중첩 장면 내부는 대상이 아닙니다. 같은 항목에 Advanced Scene Switcher 등의 규칙을 함께 쓰면 표시 명령이 충돌할 수 있으므로 한쪽을 중지하세요. Lift Trace가 다른 프로그램을 자동으로 끄지는 않습니다.

OBS 비밀번호와 선택은 로컬 데이터 폴더의 `automation.json`에 저장됩니다. 이전에 저장한 유효한 `automation-template.png`가 있으면 그대로 우선 사용하며, 없으면 내장 기준을 사용합니다. 이 개인 파일들은 일반 **설정 내보내기**에 포함되지 않습니다. 새 폴더로 업데이트한 뒤에는 다시 연결하고 대상을 선택·저장한 뒤 시작하세요. 플레이 화면 등록은 필요 없습니다. 개인 파일을 저장소나 문제 제보에 첨부하지 마세요.

동작 변화와 지연 기록은 데이터 폴더의 `automation-events.jsonl`과 직전 로그 `.1`에서 확인할 수 있습니다. 화면 이미지나 OBS 비밀번호는 이 진단 로그에 넣지 않습니다. 다른 로그와 개인 설정 파일까지 함께 공유하지 마세요.

## 업데이트와 삭제

**업데이트할 때:** 기존 설정 화면에서 **설정 내보내기**를 눌러 파일을 저장하세요. Lift Trace와 OBS를 닫고, 새 Windows ZIP을 **새 폴더**에 압축 해제합니다. 새 LiftTrace.exe를 열어 **불러오기**를 누르고 저장한 설정 파일을 선택합니다. 컨트롤러를 다시 선택하고 OBS의 너비·높이와 X·Y 위치를 앱에 표시된 값으로 맞추세요. 새 버전이 잘 작동하는 것을 확인한 다음 이전 폴더를 삭제하면 됩니다.

OBS와 같이 켜기를 설정했다면 OBS의 스크립트 목록에서 이전 항목을 지우고 새 폴더의 파일을 추가합니다.

**삭제할 때:** 남기고 싶은 설정을 먼저 내보냅니다. OBS에서 **Lift Input**과 선택 사항으로 등록한 Lift Trace 스크립트를 제거합니다. Lift Trace와 OBS를 닫은 뒤 압축을 푼 폴더를 삭제하세요.

## 문제 해결

| 상황 | 먼저 해볼 것 |
| --- | --- |
| LiftTrace.exe가 없어요 | 받은 파일 이름에 **windows-x64**가 있는지 확인하고 **압축 풀기**로 전체 파일을 꺼내세요. |
| 작은 창은 있는데 설정 화면이 없어요 | 작은 창의 **설정 열기**를 누르세요. |
| 프로그램을 열 수 없거나 저장할 수 없어요 | **문서** 폴더에 다시 압축을 풀고 폴더 안의 파일을 옮기지 않은 상태에서 실행하세요. |
| Windows나 보안 프로그램이 막아요 | 현재 버전에는 코드 서명이 없습니다. 이 프로젝트의 Releases에서 받은 것인지 확인하고 차단 메시지를 제보하세요. 보호 기능을 끄지 마세요. |
| 이미 사용 중이라는 오류가 나요 | 본인이 먼저 켜 놓은 Lift Trace 창을 닫고 다시 실행하세요. 계속되면 오류 문구를 알려주세요. |
| 컨트롤러 목록이 비어 있어요 | 연결을 확인하고 **검색**을 누르세요. INFINITAS에서 쓰는 컨트롤러 모드인지도 확인하세요. |
| 건반이나 스크래치가 다르게 나와요 | **컨트롤러 설정**을 다시 누르고 안내한 건반이나 턴테이블만 조작하세요. |
| 입력 노트가 안 보여요 | **LIFT**가 0인지 확인하세요. 게임의 LIFT 값을 넣거나 **직접 정하기**로 높이를 정한 뒤 건반을 누르세요. |
| OBS에 설정 화면이 보여요 | **OBS에 붙여넣을 주소 복사**를 다시 누르고, OBS의 **Lift Input → URL**에 붙여넣으세요. |
| OBS에서 표시가 잘려요 | 앱의 **너비 복사**, **높이 복사**로 OBS의 너비·높이를 다시 맞추세요. |
| OBS에서 위치가 어긋나요 | **1P/2P**와 **LIFT**를 확인한 뒤, 5단계에 따라 **변환 초기화**와 가로·세로 위치 붙여넣기를 다시 진행하세요. |
| 게임과 움직임이 맞지 않아요 | 게임과 앱의 녹숫·LIFT·SUDDEN+가 같은지 확인하고 **속도 보정**과 **표시 지연**을 각각 조절하세요. |

해결되지 않으면 GitHub의 **Issues**에서 **어느 버튼까지 눌렀는지**, **어떤 화면이나 오류가 나오는지** 알려주세요. 컨트롤러 문제라면 제품 이름도 적어 주세요. 모르는 항목은 비워도 됩니다. 한국어·일본어·영어로 제보할 수 있습니다.

이 프로그램은 건반과 스크래치 입력을 보여줍니다. 게임의 판정이나 실제 롱노트인지를 알아내지는 못합니다. 컨트롤러와 게임 캡처 환경에 따라 추가 조정이 필요할 수 있습니다.
