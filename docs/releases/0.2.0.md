## English

Choose how key input notes look, with optional INFINITAS visibility control that better handles brief capture delays and FULL COMBO effects.

- **Input note appearance:** turn bodies off to show only the heads for keys 1–7. Bodies default to on. Tune brief-input thresholds and retained length with comparison samples, a slider and presets, then **Apply and save** or **Revert edits**. Actual input records and scratches stay unchanged.
- **Optional automatic visibility · experimental:** detects play UI in the checked 1P layout and shows selected OBS items. During FULL COMBO effects, a secondary reference can preserve an already confirmed play state but cannot start a new session. Late observations are discarded while polling continues. Longer observation gaps hide items and require fresh confirmation. Bounded diagnostic logs record state transitions.
- **Standalone use remains:** no Core or iPad remote is required. Starting saved visibility from the OBS helper is opt-in and off by default, applying only to servers it starts. Recording control, song-title OCR and remote controls are outside this release.

To update, export settings, extract the new ZIP into a **new folder**, and import settings. Update the OBS script path if used, and recheck local automatic-visibility connection and targets. Follow the [user guide](https://github.com/d0vetam3r/lift-trace/blob/v0.2.0/docs/USER_GUIDE.en.md).

## 日本語

鍵盤入力ノーツの見た目を選べるようになり、任意のINFINITAS自動表示は一時的な取得遅延やFULL COMBO演出に対応します。

- **入力ノーツの表示：** 胴体をオフにすると1–7鍵の頭だけを表示します。初期値はオンです。短い入力の基準時間と残す長さは比較例・スライダー・プリセットで調整し、**適用して保存**または**変更を戻す**で確定・取消できます。実際の入力記録とスクラッチは変えません。
- **任意の自動表示・実験機能：** 確認した1P配置のプレイUIを検出して選択したOBS項目を表示します。FULL COMBO演出中の補助基準は、確認済みのプレイ状態だけを維持し、新しいプレイ開始には使いません。遅い観測は捨てて次の取得を続けます。長い観測空白の後は非表示と再確認を行い、制限付きの診断ログに状態遷移を残します。
