Controller setup

Settings change only when you click Apply. Keep this page open while following the prompts.

If the turntable is not detected, cancel and check your controller's PC/joystick mode. Manual button and axis settings are available under Controller mapping and appearance.

OBS setup

Place the overlay in the LIFT area.

  1. Choose 1P or 2P, enter your game's green number, LIFT, and SUDDEN+, then click Match 1080p lane size.
  2. In OBS, click + under Sources, choose Browser, give it a name, and click OK.
  3. Click Copy address for OBS below. Paste it into the field named URL in OBS. Leave Local file unchecked.
  4. Enter the Width and Height shown below, then click OK.
  5. Fit the game to the full 1920 × 1080 canvas. Right-click the overlay source, choose Transform → Reset Transform, then Transform → Edit Transform.
  6. Copy the horizontal position below into Position X and the vertical position into Position Y. Set Alignment to Top Left and Bounds Type to Automatic (No bounds in older OBS versions). After Reset Transform, leave Size unchanged to keep 100% scale.
  7. The size and position already set in OBS do not change automatically. Copy changed values into OBS again.
