# Lift Trace

[한국어](README.md) · [日本語](README.ja.md) · [English](README.en.md)

**beatmania IIDX INFINITASの配信に使えるOBS入力オーバーレイです。**

鍵盤やスクラッチの操作を、**判定ラインの下にあるLIFT領域**に入力ノーツとして表示します。ゲームのレーンと位置・速度を合わせると、ゲームのノーツが判定ラインに到達した後も、自分の入力として下へ続いていく様子を配信に映せます。

**[Windows版をダウンロード](https://github.com/d0vetam3r/lift-trace/releases/latest)** · [順番に進める使い方](docs/USER_GUIDE.ja.md)

![判定ラインの下に入力ノーツが落ちる動作例](docs/images/lift-trace-demo.gif)

*動作を説明するデモです。判定ラインより上のノーツは例示で、下側にはLift Traceの入力ノーツを表示しています。実際のゲームプレイ映像ではありません。*

## 始め方

Windows 10/11（64ビット）、OBS Studio、INFINITAS、対応コントローラーが必要です。**Pythonのインストールやコマンド入力は不要です。**

1. [最新リリース](https://github.com/d0vetam3r/lift-trace/releases/latest)の **Assets** を開きます。名前が `lift-trace-windows-x64-` で始まり、`.zip` で終わるファイルをダウンロードします。
2. ZIPファイルを右クリックして **すべて展開** を選びます。展開した **LiftTrace** フォルダーの **LiftTrace.exe** をダブルクリックします。
3. ゲームで使っている緑数字・LIFT・SUDDEN+を入力します。**入力ソース** を **コントローラー · プレイ中も入力を検出** に切り替えて自分の機器を選び、**コントローラー設定** の案内に従います。ターンテーブルが左なら **1P**、右なら **2P** を選びます。
4. [OBSの設定手順](docs/USER_GUIDE.ja.md#4-obsにアドレスとサイズを貼り付ける)に沿って、オーバーレイのアドレス・サイズ・位置をOBSにコピーします。

展開したフォルダー内のファイルは一緒に保管してください。ガイドは、ゲーム画面がすでにOBSに映っている状態を前提に、操作するボタンと確認する内容を順番に説明します。

## 主な機能

- **鍵盤入力の表示：** 7つのレーンで胴体または頭だけの表示を選び、短い入力の表示の長さも調整できます。実際の入力記録は保持します。
- **スクラッチの方向表示：** 時計回り ↻ は淡いコーラル色、反時計回り ↺ は濃いコーラル色です。回転方向が変わると矢印と色も切り替わります。
- **高さと速度の調整：** 緑数字・LIFT・SUDDEN+から落下速度を計算します。高さはLIFTに合わせるか、手動で指定できます。表示の高さだけを変えても速度は変わりません。
- **OBSへの配置と起動：** アドレス・幅・高さ・X/Y位置をコピーできます。任意のOBS連携を設定するとOBSと一緒に起動し、OBSから起動したオーバーレイはOBSの終了時に停止します。

入力ノーツはコントローラーの操作を表し、ゲームの譜面や判定は読み取りません。計算は、**1920 × 1080のOBS画面全体**にゲームを表示する構成が前提です。2Pの位置は左右対称にした計算値を出発点とし、実際の画面に合わせて調整できます。

## 関連プロジェクトと長期的な方向性

Lift Traceは、**INFINITAS配信向けのモジュール型ツールエコシステム**で入力の可視化を担うプロジェクトです。各プロジェクトは個別のリポジトリと実行単位を持ち、必要な機能だけを任意で連携させます。

| プロジェクト | 役割 | 現在の公開状況 |
| --- | --- | --- |
| [Lift Trace](https://github.com/d0vetam3r/lift-trace) | 実際の入力の可視化、任意のプレイ検出とオーバーレイ自動表示 | 公開 · MIT |
| [INFINITAS Live Core](https://github.com/d0vetam3r/infinitas-live-core) | OBS映像の一時保持・保存、曲名認識、マイク制御とローカルAPI | 非公開 |
| [INFINITAS Remote](https://github.com/d0vetam3r/infinitas-remote) | iPad用Webリモコン、キー入力、Coreの状態表示と保存・マイク操作の要求 | 非公開 |

**Lift TraceはCoreやRemoteなしで単独実行できます。** 連携時はCoreのOBSアダプターがオーバーレイの表示状態を監視し、RemoteのPCサーバーがCoreのローカルHTTP APIを呼び出します。Lift TraceからCoreを呼び出すことはなく、他のプロジェクトのインストールや起動も必要ありません。Remoteのキー入力・ボタン設定・楽曲推薦もCoreなしで利用でき、映像保存・曲名表示・OBSマイク制御にのみCoreが必要です。両連携プロジェクトはLift Traceの配布物には含まれません。

長期的には、独立した実行と任意の連携を維持しながら、**INFINITAS配信向けのモジュール型オープンソースエコシステム**へ発展させることを目指します。現在オープンソースとして公開しているのはLift Traceのみです。Live CoreとRemoteは非公開を維持し、ライセンスと同梱資料の配布条件を確認したうえで、将来の公開を別途判断します。非公開リポジトリのリンクはアクセス権のあるアカウントでのみ開けます。
