# Lift Trace

[English](README.md) · [한국어](README.ko.md) · [日本語](README.ja.md)

**beatmania IIDX INFINITAS**で押した鍵盤とスクラッチの動きをOBSに表示するアプリです。鍵盤を押すかスクラッチを回すと、判定ラインの下に **入力ノーツ** が落ちます。入力ノーツはコントローラーの操作を表したもので、ゲームの譜面を読み取ったノーツではありません。

**プロトタイプです。** Windows 10/11（64ビット）向け。日本語・韓国語・英語に対応しています。

コードとドキュメントの作成にはAIツールを幅広く使用しています。現在は初期の試作版です。[検証状況と未確認の項目](docs/VALIDATION.md)では、確認済みの内容と、実機でのテストや人によるレビューが必要な内容を分けて記載しています。この文書は英語です。

## アプリを使いたい

**プログラミング、Pythonのインストール、コマンド入力は不要です。**

初回の公開リリースを準備しています。ReleasesにWindows ZIPがない場合、実行ファイルはまだそこからダウンロードできません。

1. このGitHubページの **Releases** を開き、最新バージョンの **Assets** を展開します。
2. 名前が **`lift-trace-windows-x64-`** で始まり、**`.zip`** で終わるファイルをダウンロードします。間の数字はバージョンなので、変わることがあります。
3. ダウンロードしたファイルを右クリックして **すべて展開** を選びます。展開した **LiftTrace** フォルダーの **LiftTrace.exe** をダブルクリックします。
4. [最初から順番に進める使い方](docs/USER_GUIDE.ja.md)に沿って、ゲームの数値入力、コントローラーの設定、OBSへのアドレス貼り付けを行います。

操作するボタンと、各手順で確認する内容を説明します。LIFTの値から表示の高さが自動で計算されます。高さを手動で指定することもできます。ゲームを1080p画面全体に表示する構成では、レーンサイズを合わせるボタンを押し、計算された横・縦位置をOBSにコピーして配置します。

OBS Studio、INFINITAS、対応コントローラーは別途必要です。展開したフォルダー内のファイルは一緒に保管してください。起動しない場合は [困ったときは](docs/USER_GUIDE.ja.md#困ったときは) を確認してください。

## プロジェクトについて

現在の表示は、**1920 × 1080のOBS画面全体にゲームを表示する構成**が前提です。表示の高さを変えても、計算される落下速度は変わりません。位置とタイミングは実際のゲーム画面に合わせて調整します。ゲームの判定ではなく、入力を表示します。
